# hospital-management-sql-analytics
Relational database design and advanced healthcare analytics using SQL (CTEs, Joins, Window Functions).

**Project Description**
Designed and implemented a relational database for a Hospital Management System to optimize data flow across 8 tables. I established primary/foreign key relationships and wrote complex SQL scripts for healthcare analytics.

Key technical achievements:

Engineered advanced queries using Joins and CTEs to rank department capacities.

Performed workload analysis to identify doctor-to-hospital distribution.

Segmented patient demographics and tracked appointment trends to improve operational decision-making for hospital administration.

**Key Technical Features**
Multi-Table Joins: Integrated data from hospitals, doctors, patients, and appointments to create a unified view of facility operations.

Common Table Expressions (CTEs): Utilized CTEs to organize complex logic, such as calculating doctor counts and filtering hospital performance metrics.

Window Functions (DENSE_RANK): Applied DENSE_RANK() to identify the second-largest department by room capacity in each hospital, providing granular infrastructure insights.

Data Transformation: Categorized patient age groups (Pediatric, Adult, Geriatric) using conditional logic to assist in specialized care analysis.
